# Contributing

Thanks for considering a contribution! To keep this list useful, please follow these guidelines.

## Before submitting

- Make sure the tool is **actively maintained** (check for recent updates, an active site, or ongoing support).
- Check the list to avoid **duplicate entries**.
- The tool should be **genuinely useful** to content creators — not a placeholder page or a site with no real functionality.

## Submission format

Add your entry in the appropriate category, keeping alphabetical order within that category:

```markdown
- [Tool Name](https://example.com) - One factual, neutral sentence describing what it does.
```

- Keep descriptions **factual and neutral** — no superlatives ("best," "amazing," "#1"), no marketing language.
- One sentence only. If the tool needs more explanation than that, it may not be a good fit for a link-list format.
- Confirm the link works before submitting.

## Pull request checklist

- [ ] Entry is in the correct category
- [ ] Entry is placed in alphabetical order within its category
- [ ] Link is valid and working
- [ ] Description is one sentence, factual, and neutral in tone
- [ ] No duplicate entry already exists

## A note on self-submissions

If you're submitting your own tool or product, that's fine — just hold it to the same standard as any other entry: accurate, neutral, and genuinely useful. Maintainers reserve the right to edit descriptions for tone or accuracy, or to decline entries that don't fit the list's purpose.

## New categories

If you think a new category is needed, open an issue first to discuss it before submitting a PR.
